# kankan-users

The public website for KanKan: https://getkankan.com

Static pages served by GitHub Pages. No build step, no server, no cookies, no third-party scripts.

- `index.html`: home page
- `support.html`: help and FAQ
- `privacy.html`: privacy policy
- `mentions-legales.html`: legal notice
- `contact.html` + `contact.js`: "Report a problem". The page reads a report from the link the app opens, shows it, and lets you copy it and email it to support@getkankan.com. The page sends nothing itself. The format is in `CONTRACT.md`.
